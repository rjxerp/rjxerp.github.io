文档格式转换工具

专为 Windows 平台设计的图形界面文档转换工具，批量把 doc、docx、pdf、Excel、txt 转为标准 Markdown。

查看源码仓库 返回作品列表

项目概览

这个工具解决的是一个具体麻烦：手上有一堆 Office 与 PDF 文档，但需要在 GitHub、知识库或内容平台上以结构化文本呈现。手工复制粘贴不仅慢，标题层级、列表结构与表格格式几乎全部丢失。

工具采用 Python 开发、基于 Tkinter 构建图形界面，支持批量处理、自定义转换选项与实时进度显示。转换时会自动识别文档结构，保留标题、列表与表格等格式；图片可选择以链接或嵌入两种方式处理。整个过程不依赖 Office 软件或网络服务，纯本地运行。

适用场景包括：旧格式文档迁移到 Markdown 以便纳入版本控制与在线发布；各类文档统一转换为 Markdown 便于管理与检索；Office 文档转为 Markdown 后直接发布到博客、GitHub 等平台。

界面与流程预览

核心功能

  • 多格式批量转换，一次处理多个文件
  • 智能识别文档结构，保留标题、列表、表格格式
  • 图片提取并可选链接或嵌入方式
  • 实时进度与状态反馈，支持取消操作
  • 丰富的转换选项配置
